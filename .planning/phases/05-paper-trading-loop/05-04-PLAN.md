    symbol in the union of both position dicts, compute delta =

    pending_qty.get(symbol) == abs(delta) exactly (an exact match, per
    T-05-04's conservative-default rule -- never a tolerance band);
    otherwise "unexplained". Return one dict per non-zero delta:
    {"symbol", "local_qty", "broker_qty", "classification"}.

    trader.risk.breakers.append_breaker_event's shape).

    trader.risk.breakers.read_breaker_state(conn); if any of
