<objective>
Build Phase 5's reconciliation loop: a pure classification function
(explainable vs unexplained divergence, mirroring `trader/risk/breakers.py`'s
event-log/re-derive-state/human-only-clear discipline exactly), the combined
`is_entry_halted` gate the entry pipeline consults before every submit, and
the one human-only CLI that can ever clear a halt -- which now also logs
that clear as a `manual_restart_required` ops-log entry, so the two-week
"zero manual interventions" audit never has to rely on memory (plan-checker
BLOCKER 3).

Purpose: standing rule 4 ("if the system and the exchange disagree, the
system halts") implemented as code, not convention, before the entry
pipeline (05-06) is wired to respect it -- and every human clear of that
halt is durably logged the moment it happens.
Output: trader/paper/reconcile.py, trader/paper/clear_halt.py, Task
Scheduler artifacts for the 60-second reconciliation cadence.
</objective>
