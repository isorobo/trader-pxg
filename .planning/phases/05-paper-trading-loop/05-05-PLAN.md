<objective>
Build the guardian: the 5-minute-cadence, one-shot exit-monitoring process
that re-evaluates every open paper position's locked `EXIT_PROFILE` against
the latest price (IBKR delayed data for stocks, ccxt live ticker for the
crypto sim leg, D-02), submits self-computed marketable exit orders through the
same idempotency path entries use, records real-format `paper_trades` rows,
and evaluates D-01's five live kill conditions every tick, auto-retiring
any strategy_config that trips one.

Purpose: PAPER-02 and D-01's live kill-condition enforcement, fully testable
against a mocked broker before any IBKR connection exists.
Output: trader/paper/guardian.py, Task Scheduler artifacts for the 5-minute
cadence.
