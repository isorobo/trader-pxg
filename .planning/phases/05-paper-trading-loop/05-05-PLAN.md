<objective>
Build the guardian: the 5-minute-cadence, one-shot exit-monitoring process
that re-evaluates every open paper position's locked `EXIT_PROFILE` against
the latest price (IBKR delayed data for stocks, ccxt live ticker for the
crypto sim leg, D-02), submits self-computed marketable exit orders through
the same persist-before-submit idempotency path entries use (including the
date-independent crash-recovery matching, BLOCKER 1), records real-format
`paper_trades` rows, evaluates D-01's five live kill conditions every tick
(auto-retiring any strategy_config that trips one), evaluates Phase 4's
account-level circuit breakers against the real paper equity curve and
fires a real-time alert on any new trip (W1), and folds in D-11's
twice-daily heartbeat directly into the existing tick -- no fourth
scheduled task needed (BLOCKER 4).

Purpose: PAPER-02, D-01's live kill-condition enforcement, and the missing
wiring that makes `is_entry_halted`'s Phase-4-breaker check (05-04)
actually mean something in a live run -- all fully testable against a
mocked broker before any IBKR connection exists.
Output: trader/paper/guardian.py, Task Scheduler artifacts for the 5-minute
cadence.
