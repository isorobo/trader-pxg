<objective>
Wire the live entry pipeline: on each trading day shortly after US open,
scan the frozen 18-symbol stock universe with the momentum_stock/loose
signal (D-01, D-02, D-14), run Phase 4's risk gate and sizer completely
unmodified (D-08 -- no bypass path exists), round the sizer's dollar output
down to whole shares (Pitfall 2), and assign each new position one of the
five live exit-profile configs via a hash keyed on SYMBOL ALONE (no date
component -- day-stable identity is required for crash-recovery to ever
find the same order again, plan-checker RESIDUAL BLOCKER 1). Every
invocation first runs an UNSCOPED STEP 0 heal pass over every unresolved
local order in the whole table (`get_all_unresolved_orders`, no
strategy_id/symbol filter) BEFORE candidate scanning and BEFORE the halt
gate, so a crash-orphaned order is healed even when its own symbol never
fires a fresh signal again. The narrower per-candidate heal check from the
prior revision is kept as a second, defensive layer for whatever fires
fresh today, then the combined Phase-4-breaker + reconciliation halt gate
runs before persisting a brand-new `pending_submit` order and calling the
broker.

Purpose: PAPER-01, the single riskiest piece of live-money-adjacent logic
in this phase, fully proven against a mocked broker before touching a real
Gateway connection -- with a crash at any point in the order lifecycle,
discovered on any later calendar day, for ANY symbol (whether or not it
ever trades again), always healing instead of double-ordering or being
silently forgotten.
Output: trader/paper/entry_pipeline.py, Task Scheduler artifacts for the
once-daily entry run.
</objective>
