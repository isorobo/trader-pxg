<objective>
Wire the live entry pipeline: on each trading day shortly after US open,
scan the frozen 18-symbol stock universe with the momentum_stock/loose
signal (D-01, D-02, D-14), run Phase 4's risk gate and sizer completely unmodified
(D-08 -- no bypass path exists), round the sizer's dollar output down to
whole shares (Pitfall 2), assign each new position one of the five live
exit-profile configs via a deterministic rotation, check the combined
Phase-4-breaker + reconciliation halt gate immediately before every submit,
and place idempotent paper orders through the same order_ref path the
guardian uses.

Purpose: PAPER-01, the single riskiest piece of live-money-adjacent logic
in this phase, fully proven against a mocked broker before touching a real
Gateway connection.
Output: trader/paper/entry_pipeline.py, Task Scheduler artifacts for the
once-daily entry run.
</objective>
