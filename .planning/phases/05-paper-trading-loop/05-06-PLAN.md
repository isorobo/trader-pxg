<objective>
Wire the live entry pipeline: on each trading day shortly after US open,
scan the frozen 18-symbol stock universe with the momentum_stock/loose
signal (D-01, D-02, D-14), run Phase 4's risk gate and sizer completely
unmodified (D-08 -- no bypass path exists), round the sizer's dollar output
down to whole shares (Pitfall 2), assign each new position one of the five
live exit-profile configs via a deterministic rotation, and -- per every
candidate -- FIRST check for a crash-orphaned order via the
date-independent `get_unresolved_orders`/`find_unresolved_match` pair
(healing it unconditionally, regardless of the halt gate), and ONLY THEN
check the combined Phase-4-breaker + reconciliation halt gate before
persisting a brand-new `pending_submit` order and calling the broker
(plan-checker BLOCKER 1: heal-before-halt, and matching that survives a
crash discovered on a LATER calendar day).

Purpose: PAPER-01, the single riskiest piece of live-money-adjacent logic
in this phase, fully proven against a mocked broker before touching a real
Gateway connection -- with a crash at any point in the order lifecycle,
including one that isn't discovered until the next trading day, always
healing instead of double-ordering.
Output: trader/paper/entry_pipeline.py, Task Scheduler artifacts for the
once-daily entry run.
</objective>
