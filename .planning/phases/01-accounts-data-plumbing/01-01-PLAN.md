From trader/ground_truth/db.py (unmodified by this plan — read for pattern only):
```python
def get_connection(db_path: str = "data/trader.db") -> sqlite3.Connection:
    conn = sqlite3.connect(db_path, timeout=10)
    conn.execute("PRAGMA journal_mode=WAL;")
    conn.execute("PRAGMA busy_timeout=5000;")
    ensure_schema(conn)
    return conn
```
This plan's `trader/data/db.py` mirrors the same pragmas but drives schema creation through `apply_migrations` instead of a hardcoded `ensure_schema`. Both modules may open the same `data/trader.db` file safely because every `CREATE TABLE IF NOT EXISTS` statement is idempotent.
