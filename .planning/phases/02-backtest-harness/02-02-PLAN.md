  <behavior>
    - PointInTimeIterator(bars_by_symbol: dict[str, pd.DataFrame]) builds one internal cursor per symbol from each DataFrame's index (dates) and OHLCV columns; construction does not require a live get_daily_bars call — tests build bars_by_symbol from small fixture DataFrames (mirroring _fixture_bars) so the class itself has zero network/DB coupling
    - .calendar is the sorted, de-duplicated union of every symbol's index dates, as a list of pd.Timestamp
    - .advance_to(date) moves every symbol's pointer forward to include all bars with index <= date; calling it twice with the same date is a no-op (pointer does not move further); calling it with an earlier date than already reached raises ValueError (pointers never move backwards)
    - .history(symbol) returns only bars with index <= the date last passed to advance_to — a test constructs a 10-bar fixture, calls advance_to on day 5, and asserts len(iterator.history(symbol)) == 5 and the last row's date == day 5's date, with no row beyond it
    - .history(symbol) before any advance_to call returns an empty frame/array (length 0), not the whole series
    - .bar_on(symbol, date) returns a dict with keys open/high/low/close/volume when that exact date has a bar for that symbol, else returns None — a test using two symbols with different trading calendars (e.g. one missing a specific date) proves the None path
    - A regression test proves history()'s returned object cannot be used to see beyond the pointer even if the caller holds a reference across a later advance_to call for a DIFFERENT symbol (per-symbol pointers are independent)
  </behavior>
