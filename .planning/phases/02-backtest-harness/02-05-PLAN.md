    - ExitResult carries reason: str (one of 'stop','take_profit','trailing_stop','scale_out','time_stop','eod_flat' — matching migrations/0003_backtest.sql's CHECK constraint exactly), raw_price: float, exit_fraction: float (0 < fraction <= 1.0), new_watermark: float | None
    - Entry-bar test: a position entered at this bar's open with a stop set; this SAME bar's low breaches the stop -> evaluate_exit called on the entry bar itself (days_held=0) returns reason='stop', not None — proves the entry bar is checked, not skipped (Pitfall 2)
    - Tie-break test: a bar whose low breaches the stop AND whose high breaches the TP in the same bar -> evaluate_exit returns reason='stop' (D-05), never 'take_profit'
    - Gap-through test: bar opens below the stop price -> raw_price equals the bar's open (worse than the stop price), reason='stop'
    - Trailing no-lookahead test (Pitfall 3): profile.trailing_pct=0.05, prior watermark=100.0 (i.e. highest close as of the END of the previous bar); THIS bar's own high is 110 (a new high) and THIS bar's low is 94 (below 100*(1-0.05)=95, which would NOT be breached if the watermark were wrongly updated to 110 first, giving a new level of 104.5 — the position would then wrongly appear un-stopped at low=94 only if watermark used 110; with the CORRECT prior-close-only watermark of 100, the trailing level is 95, and low=94 breaches it) -> evaluate_exit returns reason='trailing_stop' using the level derived from the prior watermark (95), and the returned new_watermark for use starting the NEXT bar reflects this bar's own close (updated AFTER the check, never before)
    - Evaluation-order test: a profile with eod_flat=True AND a stop set, on a bar where both conditions are independently true -> evaluate_exit returns reason='eod_flat' (D-10's first-in-order item wins over stop when both fire on the same bar)
    - eod_flat fill test: reason='eod_flat' -> raw_price equals that bar's close (A4's daily-bars interpretation), exit_fraction=1.0
    - time_stop test: profile.max_hold_days=3, days_held=3, no other condition true -> evaluate_exit returns reason='time_stop', raw_price equals that bar's close, exit_fraction=1.0
    - scale_out test: profile.scale_out=((0.10, 0.5),), bar's high >= entry_price*1.10 -> evaluate_exit returns reason='scale_out', exit_fraction=0.5, and the position's scale_out_triggered set records 0.10 as fired so a later bar's evaluate_exit call does not re-fire the same tranche
    - No-exit test: none of the profile's conditions are met on a bar -> evaluate_exit returns None
