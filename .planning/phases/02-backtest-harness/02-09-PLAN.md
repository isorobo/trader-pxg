    - Hard N floor: asserts len(trades) >= 3000 — if the cached history is ever insufficient, this assertion fails loudly rather than silently running an underpowered test
    - Non-circular expected_bias: computed as the mean, across all trades, of -(fees + slippage) expressed as a fraction of that trade's notional (entry_price * qty) — i.e. read directly from each trade row's own fees/slippage columns (deterministic, config-derived quantities), never from the trade's pnl column
    - Standard error: se = statistics.stdev(pnl_pct_list) / math.sqrt(len(trades)) where pnl_pct_list is each trade's pnl expressed as a fraction of its notional
    - Band assertion: expected_bias - 3*se <= statistics.mean(pnl_pct_list) <= expected_bias + 3*se
    - Hard fail-safe: asserts statistics.mean(pnl_pct_list) < 0 explicitly, independent of the band check, so a harness bug that happens to land inside a wrongly-wide band still cannot silently pass
    - If the required cache data is missing (e.g. a fresh clone before Task 1's backfill has run), the test calls pytest.fail with a message directing the operator to run `python -m trader.backtest.sanity_universe` — it does not pytest.skip, since a silently skipped exit-gate test defeats the phase's purpose
